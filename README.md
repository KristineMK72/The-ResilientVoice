# The Resilient Voice — Next.js Store

A fully dynamic Printful-powered store built with Next.js for **Grit & Grace / The Resilient Voice**.

## Stack

- Next.js
- Printful API integration
- Deployed on Vercel

## Local development

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal.

## Deploy

Connect this repo to Vercel and set any required Printful / environment variables.
